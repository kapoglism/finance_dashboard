# 💰 Τα οικονομικά μου

Μια απλή εφαρμογή για την παρακολούθηση των προσωπικών οικονομικών. Καταχωρείς έσοδα και έξοδα και βλέπεις αμέσως τα σύνολα, το υπόλοιπο και πού πηγαίνουν τα χρήματά σου.

Φτιαγμένη με **Python** και **Streamlit**, ως project εκμάθησης προγραμματισμού.

## Λειτουργίες

- **Καταχώριση κίνησης:** έσοδο ή έξοδο, ποσό, κατηγορία, ημερομηνία και περιγραφή
- **Έλεγχοι εισόδου:** δεν επιτρέπεται κίνηση με ποσό 0, και οι κατηγορίες αλλάζουν ανάλογα με το αν είναι έσοδο ή έξοδο
- **Διαγραφή κίνησης:** επιλογή από λίστα και διαγραφή με ένα κουμπί
- **Σύνολα λογαριασμού:** συνολικά έσοδα, συνολικά έξοδα και τρέχον υπόλοιπο
- **Προειδοποίηση** όταν το υπόλοιπο γίνεται αρνητικό
- **Πίνακας** με όλες τις κινήσεις
- **Φίλτρο ανά μήνα:** τα σύνολα, ο πίνακας και η πίτα δείχνουν έναν συγκεκριμένο μήνα ή όλους
- **Γράφημα πίτας** με τα έξοδα ανά κατηγορία
- **Γράφημα γραμμής** με την πορεία του υπολοίπου στον χρόνο
- **Μόνιμη αποθήκευση:** οι κινήσεις αποθηκεύονται σε αρχείο CSV και δεν χάνονται όταν κλείνει η σελίδα

## Τεχνολογίες

- [Python 3.14](https://www.python.org/)
- [Streamlit](https://streamlit.io/) για τη σελίδα
- [pandas](https://pandas.pydata.org/) για τα δεδομένα και το αρχείο CSV
- [Plotly](https://plotly.com/python/) για τα γραφήματα

## Πώς τρέχει

> Χρειάζεται **Python 3.14**. Με την Python 3.15 κάποια πακέτα δεν εγκαθίστανται ακόμα.

1. Κατέβασε το project:
   ```bash
   git clone https://github.com/kapoglism/finance_dashboard.git
   cd finance_dashboard
   ```
2. Φτιάξε και ενεργοποίησε ένα virtual environment (Windows / PowerShell):
   ```bash
   py -3.14 -m venv venv
   .\venv\Scripts\Activate.ps1
   ```
3. Εγκατάστησε τα πακέτα:
   ```bash
   pip install -r requirements.txt
   ```
4. Τρέξε την εφαρμογή:
   ```bash
   streamlit run app.py
   ```
   Η σελίδα ανοίγει στον browser, στη διεύθυνση `http://localhost:8501`.

Οι κινήσεις αποθηκεύονται στο αρχείο `pinakas.csv`, που δημιουργείται αυτόματα με την πρώτη καταχώριση. Το αρχείο αυτό **δεν** ανεβαίνει στο GitHub, γιατί περιέχει προσωπικά δεδομένα
